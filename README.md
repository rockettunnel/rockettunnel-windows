# RocketTunnel for Windows

This is the **Windows version of RocketTunnel** — the same VPN client available on
iOS and Android, built natively for Windows 10 and 11. This repository hosts the
official Windows release downloads.

## Download & install

1. Download the latest `RocketTunnel-<version>#<build>.zip` from the
   [Releases](../../releases) page.
2. Extract the zip (right-click → **Extract All**).
3. Run `RocketTunnel-<version>#<build>.exe` and follow the setup wizard.
   - Windows will ask for administrator permission — this is required to install
     the app and its network components.
   - The installer is not yet code-signed, so Windows SmartScreen may show a
     warning. Choose **More info → Run anyway** to continue.
4. Launch **RocketTunnel** from the Start menu (or the optional desktop shortcut).

## System requirements

| | Requirement |
|---|---|
| **Minimum Windows** | Windows 10, version **1809** (build **17763**) or newer |
| **Also supported** | All versions of Windows 11 |

> The installer checks your Windows version and will refuse to install on
> anything older than Windows 10 1809, since the app cannot run there.

## Updating

Download the newest release and run its installer — it upgrades an existing
installation in place and keeps your saved configurations.

## Uninstalling

Uninstall **RocketTunnel** from **Settings → Apps → Installed apps** (or the
Control Panel). Your local settings remain on the machine in case you reinstall.
